//spring Boot Notes...
1. What is Spring Boot?

Answer:
Spring Boot is a Java framework built on top of the Spring Framework that helps developers create production-ready applications quickly. It reduces configuration using auto-configuration and provides embedded servers like Tomcat.

2. Advantages of Spring Boot
Less configuration
Auto Configuration
Embedded Tomcat/Jetty
Faster development
Production-ready features (Actuator)
3. Spring vs Spring Boot
Spring	Spring Boot
More configuration	Minimal configuration
External server required	Embedded Tomcat
Manual dependency management	Starter dependencies
Slower setup	Faster development
4. What is Dependency Injection (DI)?

Dependency Injection means Spring creates and injects objects automatically instead of you creating them using new.

Example:

@Service
public class UserService {
}
@RestController
public class UserController {

    @Autowired
    UserService service;
}
5. What is IoC (Inversion of Control)?

IoC means Spring manages the lifecycle of objects (beans), not the programmer.

6. What is a Bean?

A Bean is an object managed by the Spring container.
